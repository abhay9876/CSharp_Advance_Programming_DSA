# CSharp_Advance_Programming_DSA

## Description
This repository is created to practice and strengthen **Advanced C# Programming and Data Structures & Algorithms (DSA)** concepts.  
It contains hands-on implementations of searching, sorting, data structures, file handling, and runtime analysis organized in a **branch-wise structure**.

---

## Tech Stack
- **Language:** C#
- **Platform:** .NET 8
- **IDE:** Visual Studio
- **Version Control:** Git & GitHub

---

## Repository Structure & Branches

### `searching` Branch
- Linear Search  
- Binary Search  

Purpose:  
> To understand searching techniques and their time complexity.

---

### `sorting` Branch
- Bubble Sort  
- Selection Sort  
- Insertion Sort  
- Merge Sort  
- Quick Sort  
- Heap Sort  
- Counting Sort  

Purpose:  
> To learn sorting algorithms and compare their performance.

---

### `data-structure` Branch
- Linked List  
- Stack  
- Queue  
- Dictionary (HashMap)  

Purpose:  
> To understand core data structures and their operations.

---

### `file-handling` Branch
- StringBuilder based problems  
- FileStream (Read/Write)  
- StreamReader / StreamWriter  

Purpose:  
> To learn file I/O and stream handling in C#.

---

### `runtime-analysis` Branch
- Execution time measurement  
- Algorithm performance comparison  

Purpose:  
> To analyze runtime and understand Big-O behavior practically.

---

## Features
- Branch-wise learning
- Clean and simple C# implementations
- Core DSA coverage
- File handling with streams
- Runtime and performance analysis

---

## Learning Outcome
- Clear understanding of searching and sorting algorithms
- Strong grip on basic data structures
- Practical knowledge of file handling in C#
- Ability to analyze time complexity and performance
- Improved problem-solving and coding skills
